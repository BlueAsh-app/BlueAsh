BlueAsh 2.24.0 — Windows x64
자유 소프트웨어(GPL-3.0-or-later)입니다. 소스 코드: https://modepulse-relay.modepulse.workers.dev/source/BlueAsh-<버전>-source.zip (최신: .../source/BlueAsh-source-latest.zip). 자세한 출처는 NOTICE.txt.
타르코프 시작 알림: 매칭 로그로 화면 감시를 시작하고, GET READY 배치 화면에서 감소하는 카운트다운이 1초 이하임을 확인하면 한 번 울립니다. 로그만으로는 울리지 않습니다. 게임은 최소화하지 말고 다른 창 뒤에 두세요. 매칭 취소·게임 종료·10분 제한·알림 완료 후에는 캡처를 중단합니다.
타르코프 지도: 신호탄을 직접 쏴야 하는 플레어 탈출구는 초록 신호탄 권총·화살표 아이콘으로 표시합니다. 단순히 초록 불빛이 켜진 일반 탈출구는 기존 비상구 아이콘을 유지합니다.
지도 설정의 다섯 체크 항목은 새 설치·업데이트 후 처음 한 번 모두 켭니다(위치 스크린샷 자동 삭제 포함). 이후 체크를 풀고 저장한 선택은 다음 실행·업데이트에도 유지됩니다.
지도 단축키는 플리마켓 화면과 인벤토리 ITEM SEARCH 창에서 열리지 않습니다. 일반 인벤토리·상점·퀘스트 화면에서는 계속 사용할 수 있습니다.
타르코프 지도: 레이드 시작 후 약 3.8초 자동 탈출구 확인, F4(게임에 지정한 확인 키) 재확인, 인식 중 지도 열기 지원.
타르코프 지도: 퀘스트 마크를 누르면 퀘스트 카드(상인·목표 전체·위키 안내 글·위키 사진)가 열리고, 사진을 누르면 지도 전체로 크게 보입니다(오른쪽 위 ✕). Esc는 사진 → 카드 → 지도 순서로 닫고, 지도 키는 한 번에 닫습니다. 보스에 마우스를 올리면 호위 인원도 보입니다. 탈출구를 읽는 중에도 지도 키가 바로 먹습니다. 퀘스트 사진은 Windows의 Microsoft WebView2(Windows 11과 대부분의 Windows 10에 기본 포함)로 보이며, 없는 PC는 설치 프로그램이 함께 설치하고 ZIP으로 받은 경우 카드의 설치 버튼을 누르면 됩니다.
초록 비상구 = 탈출구, 두 사람 = PMC·SCAV 협동 탈출구, 주황 비상구 = 트랜짓.
택시 탈출구는 차량 아이콘입니다. 확인 키로 같은 행의 출발 카운트다운을 읽으면 붉은색, 출발 완료 표시를 읽으면 회색입니다. 상태는 두 번 연속 확인하며, 초록 표시만으로 입금을 단정하지 않습니다. 기본 표시는 차량의 실제 존재를 보장하지 않습니다.

등록한 열쇠를 클릭하면 사용처 지도로 이동하고 키 마커를 크게 표시해 위아래로 점프하고, 바닥에 닿을 때마다 얇은 물결 한 겹이 바깥으로 퍼지며 사라집니다. 부드럽게 점프하고 착지 순간 살짝 눌리고 흔들린 뒤 원래 모양으로 돌아옵니다. 원형 배경과 테두리는 없습니다. 마우스가 키 행을 벗어나면 강조가 꺼집니다. 마우스를 올리면 현재 언어의 키 설명과 클릭 안내가 지도 내부에 표시됩니다. 해당 언어의 설명이 없으면 영어 설명을 표시합니다.

BlueAsh는 게임할 때 화면 색감과 브라우저 볼륨을 한 번에 바꾸고,
타르코프·배그용 편의 도구를 모아 둔 트레이 프로그램입니다.

설치 / 새 버전으로 교체
1. 작업 표시줄 오른쪽 트레이의 BlueAsh를 우클릭 → 완전 종료합니다.
2. ZIP을 새 폴더에 전부 압축 해제합니다. (BlueAsh.exe 하나만 옮겨도 모든 기능이 동작합니다.)
3. BlueAsh.exe를 실행합니다. 기존 설정은 그대로 이어집니다.
※ 2.9.0부터 ModePulse가 BlueAsh로 이름이 바뀌었습니다. 설정은 그대로 이어지고, 예전 ModePulse.exe는 지워도 됩니다.

             휴대폰 BlueAsh 화면에서 타르코프 서버 상태 보기, 점검 알림 켜고 끄기

             마우스를 올리면 기능 이름이 표시됩니다. Tab과 Space 키로도 사용할 수 있습니다.

알아 두기
- 창을 닫으면 트레이로 들어가 켜 둔 기능이 계속 동작합니다. 끄려면 완전 종료를 누르세요.
  (완전 종료하면 화면이 일반 모드로 돌아갑니다.)
- 타르코프 시세·지도는 게임 위에 띄우는 창이라 전체화면에서는 보이지 않습니다.
  BlueAsh가 게임이 꺼져 있을 때 전체창모드로 바꿔 둡니다. (아이템 시세 ⚙에서 끌 수 있음)
- 배그 탑승 알림은 게임 화면을 읽으므로 배그를 최소화하지 말고 다른 창 뒤에 두세요.
- 게임 메모리·게임 파일은 읽거나 바꾸지 않고 게임에 입력도 보내지 않습니다. 게임 로그·설정 파일과 화면(Windows 화면 캡처)만 이 PC 안에서 읽습니다.
  게임 설정 파일(타르코프 전체창 모드·키 설정)은 게임이 꺼져 있을 때, 그 기능을 켠 경우에만 바꾸고 원본을 백업합니다.
  BlueAsh는 Battlestate Games·KRAFTON이 만들거나 승인한 프로그램이 아니며, 게임 약관·안티치트 정책은 바뀔 수 있습니다. 사용 여부는 각자 판단해 주세요.
- 새 버전 확인은 공개된 버전 파일만 읽고, 하루 한 번 이 PC에서 만든 임의 번호와 앱 버전만 보냅니다 (사용자 수를 세는 용도, 이름·계정·IP는 저장하지 않음).
  업데이트 화면의 "익명 사용 통계 보내기"를 끄면 번호도 보내지 않습니다.
  자세한 내용: https://modepulse-relay.modepulse.workers.dev/privacy.html
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요 (아직 코드 서명이 없는 개인 개발 프로그램).

기능별 확인 정도와 미완성 기능은 인게임 지도 ⚙ → 기능 상태 보기 (companion/FEATURES.txt)에서 볼 수 있습니다.
