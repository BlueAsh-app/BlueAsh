BlueAsh 기능 상태 — 2.23.1
(이름은 프로그램 화면과 같습니다. 확인 정도를 정직하게 적었습니다.)

[확인됨]
컨트롤 센터 · 일반 ↔ 게임 모드: 화면 감마·색감과 브라우저 볼륨 전환, 트레이 상주
타르코프 · 레이드 시작 알림: 로그로 화면 감시 시작 → GET READY 배치 카운트다운 1초 이하를 확인하면 1회 소리 알림
배그 · 비행기 탑승 알림: 매치 입장 후 대기 섬 카운트다운을 화면에서 읽어, 1이 지나고 2초 뒤 알림
  · 배그를 최소화하면 화면을 읽을 수 없습니다. 다른 창 뒤에 두세요.

[만들어졌고, 실제 게임에서 더 확인이 필요함]
타르코프 · 아이템 시세: 우클릭 → 조사 직후에만 화면을 읽어 플리마켓 시세·필요한 퀘스트·은신처 재료 표시
타르코프 · 인게임 지도: Fandom 지도 13장, 탈출구·트랜짓·PMC 스폰·보스·컬티스트 표시 (하루 1번 자동 갱신)
  · 레이드 시작 후 약 3.8초와 탈출구 확인 키 입력 시 목록을 읽습니다. 확인 중에도 지도를 열 수 있습니다. 초록 비상구는 탈출구, 두 사람은 협동 탈출구, 주황 비상구는 트랜짓입니다.
  · 택시 탈출구는 전용 차량 아이콘: 같은 행의 카운트다운을 읽으면 붉은색, 출발 완료의 빨간 표시를 읽으면 회색 (2회 연속 확인). 초록 표시만으로 입금을 단정하지 않습니다.
  · 진행 중인 퀘스트 목표(파란 원 !)는 게임 로그의 퀘스트 시작·완료 기록으로 자동 표시
  · 퀘스트 마크를 누르면 퀘스트 카드: 상인·목표 전체(이 지도 목표 강조)·위키 안내 글·위키 사진(누르면 지도 전체로 크게, ✕·Esc로 닫기), Esc는 사진 → 카드 → 지도 순서
  · 보스(흰 해골) 옆에 이번 모드의 출현 확률(tarkov.dev, 하루 1번 갱신)
  · 트랜짓으로 다음 맵에 가면 지도도 그 맵으로 바뀌고 PMC/SCAV도 이어받음
  · 보스에 마우스를 올리면 호위 인원(예: 르샬라 호위 2~4명, tarkov.dev 게임 데이터)
  · 내 열쇠·카드키: 지도 오른쪽 목록에서 이름으로 검색해 넣고 ✕로 빼면, 그 열쇠가 여는 문·트렁크를 작은 금색 열쇠(키카드는 하늘색 카드)로 표시. 목록에서 클릭해 사용처 확인 · 열쇠를 조사(상세보기)하면 뜨는 "지도에 열쇠 등록" 버튼으로도 넣고 뺄 수 있음(등록되면 초록 "✓ 지도에 등록됨")
  · 등록한 열쇠 클릭: 사용처 지도로 이동·확대 파동 강조, 마우스가 행을 벗어나면 종료. 설명은 현지화 API 캐시에서 표시합니다. 이 언어의 설명이 없으면 영어로 표시합니다.
  · 등록한 열쇠에 마우스를 올리면 위키의 잠긴 문 위치·문 안쪽 사진 (Edge WebView2, 없으면 글자만)
  · 지도 설명(탈출 조건, 보스 이름)은 화면 언어로 번역 — 탈출구 이름은 게임과 같은 영어
  · 내 위치: 레이드 중 게임 스크린샷을 찍으면 그 자리로 표시 (실시간 추적 아님, 미궁·아이스브레이커·터미널 제외)
  · 맵과 PMC/스캐브는 게임 로그로 자동 선택 (처음 쓰는 계정은 로그인 기록이 쌓인 뒤부터)
타르코프 · 은신처 진행도: 지은 레벨을 넣으면 시세 창에 남은 재료만 표시, 언허드·EOD는 창고 자동 최대
배그 · 지도 표시: M 지도 위에 비밀의 방(보라 원)·고정 차(주황 자동차)·고정 보트(노란 보트), 8개 맵 (사녹 없음), 지도에서 L로 켜고 끄기
자리 비움 알림: 휴대폰 연결(QR, 웹 알림 · 앱 설치 없음, 아이폰은 홈 화면에 추가) 후, 레이드가 시작될 때 PC에 움직임이 없으면 휴대폰 알림. 아이폰 연결·테스트 알림 확인됨, 실제 레이드 자리 비움은 확인 필요
타르코프 점검·서버 알림(휴대폰): 서버가 1분마다 확인해 PC가 꺼져 있어도 알림. tarkov.dev의 JSON 상태(json.tarkov.dev/status, 공식 데이터 그대로)를 읽고, 안 되면 공식 API를 시도(공식은 서버 요청에 403)
타르코프 · 플리마켓 판매 알림: 내 물건이 팔리면 휴대폰으로 (게임 로그의 판매 기록, 1분에 1번 묶어서)
